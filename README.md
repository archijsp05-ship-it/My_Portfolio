# 💻 Personal Portfolio Website

## 📌 About the Project

This project is a personal portfolio website developed as part of my web development internship task. It showcases my technical skills, projects, internship experience, and professional background in a clean and user-friendly interface.

The website is designed to provide an overview of my work and help recruiters and developers learn more about my skills and experience.
